# Tastes of Africa

A multi-page website celebrating African cuisine, built with HTML5, CSS and JavaScript.

## Pages
- Home, Recipes, 4 individual recipe pages (Jollof Rice, Injera, Chicken Tagine, Isombe)
- 3 region pages (West, North, East Africa), About Us, Contact

## JavaScript features (script.js)
- Recipe filter by region
- Favorites saved in localStorage
- Contact form validation (message > 20 characters) with a personalised confirmation
- Ingredient scaler (change servings)
- Dark / light mode toggle
- Newsletter sign-up message
